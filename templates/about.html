About the Project

Objective

This project applies data mining techniques to predict hospital readmission within 30 days of discharge. Early identification allows healthcare providers to intervene and reduce readmission rates.

Dataset

The model is trained on the University of Southamptons dataset containing 2,708 patient records from hospitals. Features include demographic information, admission details, lab procedures, medications, and diagnosis counts.

Methodology

  • Data preprocessing: handling missing values, encoding categorical variables, feature scaling.
  • Feature selection using correlation analysis and Recursive Feature Elimination.
  • Model: Logistic Regression (achieved ~59% accuracy) – other models were compared (Random Forest Classifier, XGBoost).
  • Evaluation: ROC-AUC, precision, recall, F1-score.

Web Application

Built with Flask (Python) and Bootstrap for a responsive UI. The model is serialized using joblib and loaded on startup. User inputs are transformed and passed to the model for real-time prediction.

Tech Stack
  • Python 3.9+
  • Flask 2.3
  • Scikit-learn 1.3
  • Pandas / NumPy
  • Bootstrap 5
